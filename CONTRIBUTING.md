# Contributing to Food Delivery App

Thank you for your interest in contributing to this project!

## How to Contribute

1. Fork the repository.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Install the project dependencies.
5. Implement your feature or fix.
6. Test your changes.
7. Commit and push your branch.
8. Open a Pull Request for review.

## Branch Naming

Use descriptive branch names:

- `feat/food-search`
- `feat/backend-api`
- `fix/cart-quantity`
- `style/mobile-responsive`

## Contribution Guidelines

- Keep changes focused on one feature or fix.
- Follow the existing project structure and coding style.
- Do not commit passwords, API keys, or environment files containing secrets.
- Explain your changes clearly in the Pull Request.
- Do not merge your own changes into `main` without review.

## Project Goal

The goal is to develop a complete food delivery application collaboratively, improving the frontend, backend, user experience, and maintainability.

Thank you for contributing!
